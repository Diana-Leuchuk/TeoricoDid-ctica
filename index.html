01 / ENTENDER

¿Qué es un diagrama
de actividad?

Un diagrama de actividad es una representación gráfica que muestra el flujo de acciones y decisiones dentro de un proceso.

Forma parte de UML (Lenguaje Unificado de Modelado) y permite comprender cómo comienza una actividad, qué pasos se ejecutan, qué condiciones se evalúan y cómo finaliza el proceso.

En Ingeniería de Software se utiliza para analizar procesos, comunicar ideas y diseñar el comportamiento de un sistema antes de programarlo.
